不同源文件之间函数的调用

对于不同源文件之间函数的调用,我们可以在声明函数之前加上extern,如:

**由于递归函数需要用到系统堆栈，所以其运行效率低于循环结构。**递归函数分以下两种↓

直接递归

当一个函数调用其本身时，我们称这个操作为直接递归

示例代码:
int ces(int a)
{
static int i = 0;
if (i < a)
{
i++;ces(a);
}
else return 0;
}

int main()
{
printf(“%d”,ces(3));
}
函数ces在main函数中被调用,然后自调用了四次;
注意,直接递归必须要用明确的、清晰的结束语句

间接递归

当一个函数调用另一个函数之后,在另一个函数之内被再次调用,称间接递归

作用域

一个 函数/变量 能够被调用的范围,称为其的作用域

在上例中,变量ces仅能在main函数中被调用,其作用域仅存在与main函数内

内部函数与外部函数

无特别声明的为外部函数,有关键字static特别声明的为内部函数.
区分外部函数与内部函数有助于避免函数重名的情况

局部变量与全局变量

在了解局部变量与全局变量之前,先了解一下程序内存占用的几个分区:

程序内存的分区

一共分为程序区、静态存储区与动态存储区
程序区存放代码与字符常量
静态存储区存放全局变量，从程序运行开始到结束占用内存始终不变
动态存储区存放局部变量，在程序运行期间动态分配内存

静态 动态
存区 静态存储区 动态存储区
释放 随程序结束 随函数结束
初始化 随程序开始 随函数开始
初始值 0或空字符 不确定

局部变量

局部变量共分两种，静态局部变量和自动局部变量

自动局部变量

未加static关键字定义的变量,加了auto关键字定义的变量

自动局部变量随函数开始进行且初始化一次，在函数调用结束后释放内存

静态局部变量

加了关键字static定义的变量

静态局部变量存放在静态存储区，在程序开始时进行初始化，在程序结束后释放内存
其初始值一般为0或空字符

寄存器变量

这是一类特殊的局部变量
当某个变量需要被频繁且有快速读取的使用需求时，可以将其定义为寄存器变量
寄存器变量存放在CPU的寄存器中，用关键字register声明
但其有几点注意点:
(1)只有自动局部变量和形参才能定义为寄存器变量
(2)一个计算机系统中的寄存器数目有限，不能定义任意多个寄存器变量
(3)局部静态变量不能定义为寄存器变量
(4)有些C语言编译器会根据变量的使用频率，自动将其声明为寄存器变量或自动局部变量，无视关键字register的管控

全局变量

全局变量是在函数外部定义的，它的作用域是从定义处到源文件结束处，如果在 函数之后/工程内的其他源文件 使用，则需要用extern关键字进行说明才能调用.
如果用static修饰全局变量，则该全局变量只能被原源文件调用，不能被工程内的其他文件调用。
